# Authentication Standard

## Identity Verification
Protected TechNova applications must verify the identity of users before granting access to protected resources.

## Passwords
Passwords must follow the organization's password requirements and must never be stored as plaintext.

## Multi-Factor Authentication
Multi-factor authentication is required for administrative access and other systems designated as high risk.

## Sessions
Applications should expire inactive sessions according to the applicable security policy.

## Credentials
Credentials and authentication tokens must not be written to application logs or source-control repositories.
