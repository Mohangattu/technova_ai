# Data Security Standard

## Sensitive Data
Sensitive company and employee information must be handled only through approved systems and processes.

## Encryption
Sensitive data should use approved encryption mechanisms during transmission and at rest where required by the applicable security classification.

## Secrets
API keys, passwords, private keys, and access tokens must be stored using approved secret-management systems.

## Logging
Applications must avoid logging credentials, authentication tokens, and unnecessary sensitive information.

## Data Retention
Data must be retained and deleted according to the applicable organizational retention requirements.

## Incident Reporting
Suspected exposure of sensitive information must be reported through the approved security incident process.
